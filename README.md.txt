Basic Office Network (Packet Tracer)

📌 Project Overview

This project simulates a small office network using Cisco Packet Tracer.

🖥️ Devices Used

- 1 Router
- 1 Switch
- 3 PCs

🌐 IP Configuration

- Network: 192.168.1.0/24
- Router: 192.168.1.1
- PCs: Assigned via DHCP

🔄 Features

- Devices connected via switch
- Router configured as default gateway
- DHCP enabled (automatic IP assignment)
- Successful communication using ping
